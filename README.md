# 🚀 PRAGATI — Studio Command Center & Production Workflow System

> **Empowering Marketing Agencies and Production Houses with Seamless Workflow, Talent Scheduling, & Real-Time Project Tracking.**

---

## 📌 Executive Summary

Unmanaged workflows in media production and marketing agencies cause up to **35% project delays**, **budget overruns**, **miscommunicated shoot schedules**, and **idle crew costs**. 

**PRAGATI** (*Progress*) solves these core operational bottlenecks under the theme of **Work Productivity and Livelihood**. It provides an all-in-one studio command center designed specifically for creative teams, production managers, crew members, and agency clients.

---

## 📸 Platform Views & Feature Highlights

### 1. 📊 Studio Overview & Real-Time Dashboard
The centralized control hub displaying active production projects, upcoming shoot calendars, total client counts, and financial revenue estimates.

- **KPI Metric Cards**: Real-time stats on *Total Clients*, *Active Projects*, *Upcoming Shoots*, and *Revenue (Est)*.
- **Project Volume Bar Chart**: Tracks monthly shoot allocations throughout the year.
- **Project Distribution Doughnut Chart**: Categorizes productions across *Feature Films*, *Music Videos*, *Commercials*, and *Corporate Projects*.

### 2. 📁 Projects Directory
A master database for organizing production pipelines and tracking shoot schedules.

- **Granular Project Attributes**: Client associations, project category tags (e.g., *Feature Film*, *Music Video*), assigned crew members, and complete date lifecycles (*Start*, *Shoot*, *Completion*).
- **Automated Deadline Alerts**: Visual flags like `⚠️ Due Today!` prevent missed post-production deliverables and shoot dates.

### 3. 📈 Real-Time Project Progress Tracker
Visual stage-by-stage tracking mechanism designed to keep clients and project managers aligned.

- **Production Phase Indicators**: Distinguishes between *Pre-Production*, *Production*, and *Post-Production*.
- **Live Progress Bars**: Direct percentage metrics (e.g., `5%`, `96%`) reflecting deliverable status.
- **One-Click Updates**: Allows production leads to adjust progress parameters instantly.

### 4. 👥 Crew & Talent Roster Management
A dedicated directory for managing technical personnel, actors, video editors, and production crew.

- **Role & Booking Tracking**: Badges indicating assigned projects (e.g., `Booked: Dooms Day`, `Booked: Music`).
- **Availability & Day Rates**: Dynamic tags (`Available`, `Unavailable`) along with custom daily fee schedules (e.g., `₹6,700/day`, `₹1,200/day`).
- **Instant Communication**: Built-in WhatsApp dispatch integration for direct outreach to cast and crew.

### 5. 🤝 Client Directory & Multi-Role Access
Dedicated views tailored to project owners and agency clients.

- **Role-Based Views**:
  - **Admin / Studio Lead View**: Full project creation, revenue analytics, crew assignment, and data control.
  - **Crew View**: Daily shoot schedules, role details, and call sheets.
  - **Client View**: Transparent access to project timelines, progress bars, and upcoming shoot dates.
